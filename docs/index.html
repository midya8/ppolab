A / THE UNCHANGED CHECKPOINT

Not a prerecorded GIF.

Every logit, value and physics step below is computed in scalar JavaScript from all original model weights. All 30 original evaluation/gate initial states are available, with no selected frames. These are newly computed scalar paths, not exact original trajectories.

Replay uses fixed initial states from the original NumPy RNG. The browser does not imitate that RNG. It runs the same trained greedy policy and Euler physics from each state. Tiny arithmetic differences amplify and can switch later actions. Tight one-step agreement does not imply trajectory agreement.

C / REPRODUCIBILITY & LIMITS

The bug is fixed.
The evidence stays honest.

The original collector reset on timeouts but kept the trace alive and used the next reset's value. The new collector stores the actual post-step observation and value before reset. Training uses separate bootstrap and trace masks. A legacy seven-array adapter uses documented reward augmentation at truncation.

Original model, optimizer, loss, physics, GAE helper, 18 tests, checkpoint, curve and images are preserved. Thirty complete native greedy episodes test the old checkpoint only; new scalar free-running paths can differ. A boundary fix does not establish a training improvement. PPO, GAE and CartPole are standard methods, not new algorithms.

Scalar binary64 arithmetic differs slightly from NumPy matrix reductions. Cross-implementation checks use stated tolerances, not bitwise equivalence. A finite sample or a 500-step replay is not a universal solve claim, calibrated probability or safe-control guarantee.
